# TEXT PROCESSING - Text Clustering

This project explores text clustering techniques using Python. It covers K-Means and Hierarchical Clustering to group text documents based on their similarities using TF-IDF representation.

The project also implements clustering evaluation using the Elbow Method and Silhouette Score to determine and assess the quality of clusters. Word Cloud visualizations are used to identify frequently occurring words in each cluster and provide insights into the characteristics of the grouped documents.

## Requirements

This project uses Python and can be run in Google Colab or Jupyter Notebook. The required libraries include pandas, scikit-learn, matplotlib, wordcloud, scipy, and numpy.
